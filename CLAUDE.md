# Finder-Win – pokyny pro Claude Code

Finder-like správce souborů pro Windows (jen Windows). Tauri 2 + React 19/TS + Rust, verze v `package.json` a `src-tauri/Cargo.toml` (+ `Cargo.lock`, `package-lock.json`).

## Stack a struktura
- `src/App.tsx` – hlavní stav a operace (historie Zpět/Znovu, schránka, drag & drop, záložky).
- `src/panel.ts` – stav jednoho panelu (`usePanel`, v `App.tsx` volaný 2× kvůli rozdělenému oknu).
- `src/commands.ts` – registr příkazů (CommandId + DEFINITIONS): jediný zdroj zkratek, menu Více, toolbaru a palety.
- `src/theme.ts` – `ThemePreference`, zrcadlo v localStorage jen pro první render; pravdu drží storage.
- `src/browser.ts` – stav jedné záložky (`TabSnapshot`); `src/columns.ts` – sloupcové zobrazení (vč. restore); `src/undo.ts` – Zpět/Znovu (limit 50, jen v paměti).
- `src/fileops.ts` – typované wrappery nad `invoke`, vč. `localizeError`.
- `src/lib/*` – `storage.ts` (settings.json přes tauri-plugin-store), `dnd.ts`, `motion.ts`, `updates.ts` (kontrola aktualizací) aj.
- `src/i18n/cs.ts` + `en.ts` – překlady; `src/components/` – UI (např. `TabBar.tsx`, `CommandPalette.tsx`).
- `src-tauri/src/main.rs` – commandy a souborové operace; `clipboard.rs` – schránka Windows (CF_HDROP); `external_drop.rs` – drop z Průzkumníku; `native_drag.rs` – tažení ven (nativní OLE drag); `shellnew.rs` – nabídka Nový (registr ShellNew).
- `winget/` + `.github/workflows/winget-manifest.yml` – manifest a workflow (bere tag jen ve tvaru `vX.Y.Z`).
- `src-tauri/nsis/Czech.nsh` – vlastní český překlad NSIS instalátoru (`bundle.windows.nsis.customLanguageFiles`).
- README existuje ve dvou verzích (`README.md`, `README.cs.md`) – měň je společně. Changelog je v `CHANGELOG.md` (README jen odkazuje).
- `docs/screenshots/`, `docs/demo.gif`, `docs/demo/` (demo data), `docs/brand/` (sociální sítě) a `scripts/docs-media/` (generátory) – viz sekce Screenshoty a demo.

## Konvence
- Texty UI jen přes `t()` a klíče v `cs.ts` i `en.ts`; hlídá `npm run i18n:check` (běží v `npm run build`). Výjimka jde označit komentářem `i18n-ignore`.
- Nový příkaz: přidat do `src/commands.ts` (CommandId + DEFINITIONS), handler do `App.tsx`, texty do obou slovníků.
- Chyby z Rustu jako `AppError { key, args }`, překlad ve frontendu (`localizeError`).
- Commandy `#[tauri::command(async)]`, argumenty v `invoke` v camelCase.
- Komentáře česky. Soubory LF (`.gitattributes`).
- Commity: „Fáze N.x: …“, vydání „Release X.Y.Z“.
- Operace s „Nahradit“ se do historie Zpět nezapisují (nešly by vrátit).

## Testování a build
- `npm run build` (i18n check + `tsc` + vite), `npx tsc --noEmit`.
- V `src-tauri`: `cargo check`, `cargo clippy -- -D warnings`, `cargo test`. Test `trash_tests` je `#[ignore]` a sahá na skutečný Koš (`cargo test -- --ignored`).
- `npm run tauri dev`; `npm run tauri build` → `src-tauri/target/release/bundle/nsis/`.
- Živé testování: spustit dev s `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9333` a přes CDP (`http://127.0.0.1:9333/json/list`) vyhodnocovat JS ve webview.

## Známé pasti
- `dragDropEnabled` v `tauri.conf.json` musí zůstat `false` – jinak WebView2 vypne HTML5 drag & drop a interní tažení přestane fungovat. Drop zvenku jde přes `postMessageWithAdditionalObjects` (`dnd.ts` → `external_drop.rs`).
- Zprávy do `WebMessageReceived` (`chrome.webview.postMessage*`) posílat jen jako řetězce (`finderWinDrop:<id>`). wry má svůj handler první a u neřetězcové zprávy vrátí chybu – WebView2 (runtime 154+) pak další handlery nezavolá a drop z Průzkumníku tiše selže. Každý drop proto v konzoli webview zanechá jeden `console.error` z Tauri IPC (cizí zpráva), je neškodný.
- Tažení ven: položky z panelu jdou od `dragstart` nativním OLE dragem (`startEntryDrag` v `dnd.ts` → `start_native_drag` v `native_drag.rs`: data ze shellu přes `BHID_DataObject`, `SHDoDragDrop` přes `run_on_main_thread`, ne uvnitř IPC; výchozí kopie přes Preferred DropEffect, Shift přesun, výsledek z Logical Performed DropEffect → událost `native-drag-end`). Nad vlastním oknem přijde jako HTML5 drop s typem `Files`, ale payload v `dnd.ts` je nastavený, takže `isExternalFileDrag` vrátí false a cíle jdou interní cestou. Rollback = `NATIVE_DRAG_OUT = false` v `dnd.ts`. Přesun ven se do Zpět nezapisuje (cíl neznáme). Záložky a oblíbené se dál táhnou HTML5. `#[implement]` potřebuje `windows-core` jako přímou závislost.
- Testy přes CDP s `Page.reload`: frontend čísluje `watch_dirs` generace od nuly, Rust si pamatuje vyšší — po reloadu watcher do přepnutí složky nereaguje (jen artefakt testu). Skutečné tažení se přes CDP nasimulovat nedá (jen syntetický HTML5) — myš přes `SetCursorPos`/`mouse_event` z DPI-aware procesu.
- Záložky: živý je jen stav aktivní záložky, ostatní jsou `TabSnapshot`; watcher (`watch_dirs`) běží jen pro aktivní. Na disk se ukládají jen při 2+ záložkách (cesta, zobrazení, řazení).
- Aplikace je GUI bez konzole: cmd/PowerShell se nesmí spouštět přes `Command::spawn` (prázdný stdin, hned skončí) – jde to přes ShellExecuteW (`shell_execute` v `main.rs`).
- Ikony a náhledy se cachují na disku v `%LOCALAPPDATA%\finder-win\{icons,thumbnails}` (Store build `finder-win-store`, `CACHE_DIR`); timeout shellu u náhledu se v paměti necachuje.
- Nastavení `theme`, `terminal`, `windowTransparency` a `transparencyStrength` (+ `transparencyStyle`, viz Acrylic níže) jsou v settings.json.
- Při změně `nsis.languages` musí mít jazyk mimo seznam Tauri vlastní `.nsh` (Tauri 2.11 češtinu nemá).
- Python na tomhle stroji není – skripty přes node.
- Na tomto stroji (hybridní GPU AMD + NVIDIA) DWM Acrylic nikdy nerozmazává – aktivní Acrylic je plochá výplň ~#232323, ostrá průhlednost znamená, že Acrylic NENÍ aktivní (Mica se nekreslí vůbec, spike ve větvi `spike/glass-mica`). Acrylic se v aktuálním buildu vůbec nepoužije (viz další odrážka).
- Rozmazaná varianta (Acrylic, styl „blur“) je v kódu, ale vypnutá a skrytá: `TRANSPARENCY_BLUR_AVAILABLE = false` v `src/lib/storage.ts`; menu `Toolbar.tsx`, paleta `commands.ts` a `windowBackdrop` v `glass.ts` se řídí tímto přepínačem; uložená „blur“ se načte a přepíše na „clear“. ČEKÁ NA TEST NA JINÉM PC (na vývojovém stroji se DWM Acrylic kreslí jen jako šedá výplň). Uživatelská nabídka: jen Průhlednost zapnuto/vypnuto (výchozí vypnuto) a Síla jemná/střední/silná (výchozí střední; volba síly průhlednost zapne).
- Vzhled 1.5 = CSS sklo jako základ (`:root[data-glass="on"]`, `src/lib/glass.ts`) + volba Průhlednost: okno je vždy `transparent` (`tauri.conf.json`, backgroundColor #00000000), plné pozadí kreslí CSS a `syncWindowBackground` (`theme.ts`). `set_window_backdrop` v `main.rs` drží stav nativního podkladu v Rustu (`BACKDROP_STATE`: žádný / DWM / accent): „acrylic“ = Tauri `set_effects(Acrylic)`, po `clear_effects` v téže session `Effect::Blur` (accent) – DWM Acrylic po SWCA ACCENT_DISABLED do restartu nenaskočí, accent ano; „off“ = jen `DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_NONE` (stav DWM), jinak `clear_effects`; „clear“ = vždy Tauri `set_effects(None)` – transparentní okno má od vytvoření vlastní nativní podklad (na tomto stroji plochá šedá výplň), proto se volá i bez dřívějšího efektu (samotný DWM atribut se do překreslení neprojeví; `SWP_FRAMECHANGED` ani přepnutí `DWMWA_USE_IMMERSIVE_DARK_MODE` nepomáhá; skrýt/ukázat okno ho rozbije); „off“ bez dřívějšího efektu nedělá nic (plné CSS podklad zakryje). Při zapnuté průhlednosti je průhledné celé okno (sidebar, výpis, horní lišta i status bar) se stejným krytím podle síly; plocha za oknem prosvítá lištou. Obsah pod lištou: bez průhlednosti se rozmazává (sklo); v průhledném okně `backdrop-filter` obsah pod lištou nerozmaže dostatečně – výsledek je poloprůhledný a pod ním prosvítá původní ostrý obsah (zkoušeno i blur 40 px s tónováním); zakrýt ho jde jen neprůhlednou vrstvou, která by zakryla i plochu. Proto se při `data-transparency` scrollery (`.fw-panel > .fw-scroll`, `.fw-column-pane`, `.fw-info-panel`) maskují (`--bars-mask` v `index.css`, `mask-image` od `--glass-top` do 100 % − `--glass-bottom`); rozložení a virtualizace se nemění. Kontrast lišty s maskou: nejhorší 5,50. Desky nad výpisem (horní deska `.fw-main::before`, status bar, lišta nové verze, hlavička seznamu) mají krytí `--see-bar = 1 − (1 − see-sidebar) / (1 − see-main)`, aby dohromady s výpisem měly krytí sidebaru. Kontrast lišty se měří v `1.5-tools` s `REGION=bars` (`contrast.mjs`) a scénou `scrolled` (`scenefx.mjs`); `matrix.sh` dává okna krátce topmost přes `scripts/docs-media/screen.ps1` (uživatel může pracovat).
- Osiřelý vite po ukončení `tauri dev` drží port 1420.
- Pokud běží `finder-win.exe`, build přepisující binárku selže – použít jiný `CARGO_TARGET_DIR`.
- CSP `connect-src` povoluje navíc jen `api.github.com`.
